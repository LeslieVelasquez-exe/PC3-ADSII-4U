SQL, Structure Query Language (Lenguaje de COnsulta estructurado) es un lenguaje de programación para trabajar con base de datos relacionales como MySQ, Oracle, etc.
MySQ es un interpretador de SQL, es un servidor cde base de datos.
MySQ permite crear base de datos y tablas, insertar datos, modificarlos, eliminarlos, ordenarlos, hacer consiultas y realizar muchas operaciones, etc..., resumiendo: administrar bases de datos.

Este tutorial tiene por objetivo acercar los conceptos inciiales para introducir en el mundo de las base de datos.
