Introducción

MySQL es la base de datos de código abierto más popular del mundo. A pesar de sus potentes funciones, MySQL es fácil de configurar y usar. A continuación, encontrará instrucciones para poner en marcha MySQL en unos sencillos pasos. También explicamos cómo realizar algunas operaciones básicas con MySQL utilizando el cliente MySQL .

Databases

La forma recomendada de instalar MySQL en Microsoft Windows es usar el instalador de MySQL.
Si durante el proceso de instalación ha optado por configurar MySQL como un servicio de Windows, que es la opción predeterminada (consulte la sección " Servicio de Windows " para obtener más información), el servidor MySQL se iniciará automáticamente una vez finalizado el proceso de instalación.

Tabla

CREATE TABLECrea una tabla con el nombre especificado. Debes tener los CREATEpermisos necesarios para acceder a la tabla.
Por defecto, las tablas se crean en la base de datos predeterminada, utilizando el InnoDBmotor de almacenamiento. Se produce un error si la tabla ya existe, si no hay una base de datos predeterminada o si la base de datos no existe.

Carga de Registros

INSERTinserta nuevas filas en una tabla existente. Las formas INSERT ... VALUES, INSERT ... VALUES ROW(), y INSERT ... SET de la instrucción insertan filas basadas en valores especificados explícitamente. La INSERT ... SELECTforma inserta filas seleccionadas de otra tabla o tablas. También puede usar INSERT ... TABLE en MySQL 8.0.19 y posteriores para insertar filas de una sola tabla. INSERTcon una ON DUPLICATE KEY UPDATEcláusula permite actualizar filas existentes si una fila que se va a insertar causaría un valor duplicado en un UNIQUEíndice o PRIMARY KEY. En MySQL 8.0.19 y posteriores, se puede usar un alias de fila con uno o más alias de columna opcionales con ON DUPLICATE KEY UPDATEpara referirse a la fila que se va a insertar.
